# net-monitor — OSS版

macOS向けの回線測定・CSV集計用シェルスクリプトです。実測CSVや自宅の機器構成、常駐設定は含めていません。

## 手動で測定する

```sh
# 必要な場合だけ自分のルーターのアドレスを指定します。
ROUTER_HOST="192.168.0.1" bash measure.sh
bash report.sh
```

ルーターを未指定にすると、その区間のpingは測りません。
CSVは `log/measurements.csv` に保存します。ログはGit対象外です。
`curl`、`ping`、`ping6`、`awk`、macOSの `system_profiler` を使います。

## 通信と注意点

測定時にはCloudflareの速度測定先へ通信します。1回につき下り約20MB・上り約10MBを使います。
従量制の回線では通信量に注意してください。接続先の利用条件・制限に従い、高頻度の自動測定は避けてください。
Wi-Fiの電波強度・速度・チャンネル等は端末上で取得します。CSVを共有する前に内容を確認してください。
一つの測定結果だけで、宅内機器や通信事業者の故障・原因を断定することはできません。
